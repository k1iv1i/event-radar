## 题目要求 → 产品能力对照（提交时可引用）

1. **同一事件识别、合并与版本演化**：规则打分（主体交集+命题一致+关键词桶）→ LLM 灰区判定 → 事件合并后处理（自动合并事件线碎片，merge 版本留痕+通知）；每次证据入库生成版本快照（before/after），演示数据 31 篇文档收敛为 4 个事件（含正确区分的独立事件）。
2. **事实/观点/推测/传闻区分及证据权重**：四分类由 LLM 抽取（逐字 quote），证据权重 = 来源权威度（公告5>权威媒体3.5>一般媒体2.5>社交1）× 声明类型系数，规则化可解释。
3. **四个时间戳**：事件发生/披露/抓取/更新——事件页顶部四瓷砖 + 时间轴上"事件发生→披露"偏移虚线 + 节点悬停三时间展示。
4. **更新、否认、更正、过期时改变结论并通知**：状态机（优先级：冲突>完结>更正>否认≈证实）+ 三种通知渠道（toast 弹窗/本事件通知/通知中心未读角标）+ 事件内置演示交互（一键上传更正公告，实时演示结论翻转与通知）。
5. **关键结论可追溯**：结论模板写明"依据：来源，披露时间，证据权重"；每条主张可点击回原文。
