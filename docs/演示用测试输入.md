# 演示视频用：在线入库测试输入（第 5 段）

> 用途：视频中通过「+ 提交新文档」实时演示主链路。以下文档均为**演示构造的测试输入**，
> 模仿真实公告格式，用于演示判定路径与通知。录视频时口头说明"这是用于演示的模拟公告"。
> 推荐用【方案 A】（更正路径）；若想演示"传闻→否认"则用【方案 B】。

**正文：**

中航电测仪器股份有限公司（以下简称"公司"）对前期披露信息予以更正：公司《关于发行股份购买资产暨关联交易实施情况的公告》中，成飞集团100%股权的交易作价披露为174.39亿元，经复核，正确数据应为174.42亿元。除上述更正外，公告其余内容不变。特此公告。

**预期系统行为：**
1. 入库后抽取为"事实"主张，命中"更正"关键词；
2. 判定为【已更正】并生成"结论更新"通知；
3. 时间线新增节点，四个时间戳齐全（披露 2025-01-18 / 抓取=当前时间）；
4. 版本演化新增 v(n+1)：更正。
