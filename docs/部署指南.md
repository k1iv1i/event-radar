# 部署指南（已完成）

> 实际方案：GitHub 存代码 → **Render** 免费云平台部署 Docker。
> （Koyeb 因被 Mistral 收购已停止新用户部署，中途换用 Render。）
> **在线产品 URL**：https://event-radar-fcy0.onrender.com

## A. 创建 GitHub 仓库（约 2 分钟，你在浏览器操作）

1. 登录 github.com（账号已就绪）
2. 右上角 ➕ → New repository
3. Repository name 填 `event-radar`，Description 随意
4. **选择 Public**（部署平台免费版要求公开；笔试题要求公开仓库）
5. **不要**勾选 "Add a README / .gitignore / license"（保持空仓库）
6. Create repository
7. 复制仓库地址（形如 `https://github.com/你的用户名/event-radar.git`），发给 Claude

之后由 Claude 完成：添加远程、推送代码（推送时浏览器会弹出 GitHub 授权窗口，你点一次确认）。

## B. Koyeb 部署（约 5 分钟，你在浏览器操作）

1. 打开 koyeb.com → Sign up → **Sign up with GitHub**（授权时选刚才的 event-radar 仓库，或选全部）
2. 进入控制台 → Create Service → 选择 GitHub 上的 `event-radar` 仓库
3. 构建方式选 **Dockerfile**，其余默认
4. Environment variables 可不配（演示数据用缓存的 LLM 抽取结果，`--offline` 模式内置；在线提交新文档仍可走规则降级主链路）
5. Deploy → 等 2-3 分钟构建完成
6. 复制生成的 URL（形如 `https://xxx.koyeb.app`），发给 Claude 填入 README

## C. 验证清单（部署后由 Claude 引导完成）

- [ ] 公网 URL 打开产品首页正常
- [ ] 三个事件可点开、时间线/版本/通知可用
- [ ] 「+ 提交新文档」在线操作可用
- [ ] URL 写入 README 头部
- [ ] 确认仓库内无 `.env`、无 API key（.gitignore 已排除，推送后需复核）
